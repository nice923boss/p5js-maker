P5JS Maker 使用說明

用時間軸製作 p5.js 動畫。每個區塊的操作步驟依畫面位置排列，可從目錄直接跳到要看的段落。

1畫面配置

編輯器分成六個區塊，點下方區塊名稱可跳到該段說明。

上方工具列：新增、開啟、儲存、復原、專案名稱、匯出
素材庫
舞台（預覽畫面）
播放控制
屬性面板
時間軸：鏡頭列、視覺軌、音訊軌
底部狀態列：目前狀態訊息

時間軸上緣的細長分隔條可以上下拖曳，調整時間軸與舞台的高度比例。

2五分鐘上手

  1. 點右側「專案設定」確認畫面尺寸（橫式、直式或方形）與影片長度。
  2. 左側素材庫切到「生成」，點一個背景（例如漸層天空），它會放在最底層並蓋滿畫面。
  3. 切到「文字」，點「大標題」加入，在舞台上雙擊文字，右側會跳到文字欄位，輸入你的標題。
  4. 在時間軸拖曳文字片段調整出現時間，拖左右兩端調整長度。
  5. 選取文字後切到右側「動畫」分頁，挑入場與出場效果。
  6. 切到「粒子」加雪花或櫻花，切到「音訊」加一段配樂。
  7. 按 Space 預覽，滿意後按 Ctrl+S 存檔，再按右上「匯出影片」。
素材可以「點一下」加到播放頭位置，也可以「拖曳」到舞台上指定位置，或拖到時間軸上指定時間與軌道。

4素材庫（左側）

基本操作

  1. 點左邊直列的分頁圖示切換類別。
  2. 點一下素材卡片：加到目前播放頭的時間，放在該時間沒有被占用的軌道；沒有空位時自動新增一條軌道。
  3. 拖曳素材卡片到舞台：放在滑鼠放開的位置。
  4. 拖曳素材卡片到時間軸：放在滑鼠所在的時間與軌道。
  5. 卡片被選取時按 Enter 也能加入。

各分頁內容

分頁內容與注意事項

5舞台（預覽畫面）

舞台顯示播放頭所在時間的畫面，所有編輯都會即時反映。

選取與移動

  1. 滑鼠移到物件上會出現外框，點一下選取；點空白處取消選取。
  2. 按住物件拖曳即可移動。拖曳時按住 Shift 只沿水平或垂直方向移動。
  3. 物件中心靠近畫面正中央時會自動吸附，並顯示對齊參考線。

縮放與旋轉

  1. 選取後拖曳四個角的方形控制點，等比例縮放。
  2. 拖曳上方的圓形控制點旋轉；按住 Shift 以 15 度為單位旋轉。

直接改內容

  • 雙擊文字物件：右側面板跳到文字欄位，可直接輸入新內容。
  • 雙擊程式碼物件：右側面板跳到程式碼欄位。

拖入檔案

從電腦把圖片或音訊檔拖到舞台，會匯入素材並放在放開的位置與目前時間。

若該屬性已有關鍵影格，在舞台上移動、縮放、旋轉會在播放頭時間記錄或更新一個關鍵影格，詳見關鍵影格動畫。鎖定的軌道上的物件無法在舞台上選取。播放中無法在舞台上拖曳物件。

7屬性面板（右側）

面板內容依目前選取的東西切換：沒選取時是專案設定，選取鏡頭列時是鏡頭，選取片段時是片段屬性。

專案設定（未選取任何片段時）

  1. 名稱：專案名稱，也是存檔與匯出的預設檔名。
  2. 畫面尺寸：下拉選 1280×720、1920×1080、1080×1920 直式短影音、720×1280、1080×1080 方形，或選「自訂尺寸」後在「寬 × 高」輸入。
  3. 影格率：24、25、30、60 fps。
  4. 影片長度：以秒為單位。按「裁到內容長度」會把長度設成最後一個片段的結尾。
  5. 背景色：所有片段下方的底色。
  6. 主音量：整部影片的總音量。

片段屬性（選取片段時）

  1. 名稱：顯示在時間軸片段上的名字，方便辨認。
  2. 開始、長度：片段出現的時間與持續秒數，也可以直接在時間軸拖曳調整。
  3. 素材起點：只有音訊檔與舊專案片段有，代表從素材的第幾秒開始播放。裁切片段左端時會自動調整。
  4. 混合模式：一般、色彩增值、濾色、覆蓋、柔光、相加發光、差異，決定這個片段和下方畫面如何疊合。
  5. 分頁「屬性」：位置與變形（中心 X、Y、縮放、旋轉、不透明度等）、濾鏡，以及該類型專屬的設定（文字內容、字型、顏色、粒子數量等）。
  6. 分頁「動畫」：入場、循環、出場效果，詳見下一段。
  7. 底部按鈕：分割（在播放頭切開）、副本（複製一份）、刪除。
播放頭不在選取的片段範圍內時，面板上方會出現提醒：這時改數值會套用在片段最近的一端。

8關鍵影格動畫

關鍵影格讓數值隨時間變化，例如物件從左邊移到右邊、慢慢放大、顏色漸變。

建立動畫的步驟

  1. 選取片段，把播放頭移到動畫開始的時間。
  2. 找到要動的屬性（例如「中心 X」），按欄位右側的 ◇。◇ 變成實心 ◆，代表此時間記錄了一個關鍵影格。
  3. 把播放頭移到動畫結束的時間。
  4. 直接改數值，或在舞台上拖曳物件。系統會在這個時間自動新增第二個關鍵影格。
  5. 按 Space 播放，物件會在兩個時間點之間平滑移動。

符號意義

符號意義
◇ 空心灰色這個屬性還沒有任何關鍵影格，改數值會套用在整段片段。
◇ 青綠色空心這個屬性有關鍵影格，但不在播放頭這一刻。改數值會在此刻新增一個。
◆ 青綠色實心播放頭這一刻有關鍵影格。再按一次會刪除它。刪掉最後一個時，數值固定為當時的值。

關鍵影格列（面板上方）

  • 顯示此處有幾個關鍵影格，或整段共有幾個時間點。
  • 速度曲線下拉選單：決定「從這個關鍵影格到下一個」的變化方式，有線性、漸快、漸慢、慢快慢、柔和、回彈、蓄力、彈簧、落地彈跳、瞬間切換。
  • 上一個／下一個按鈕：播放頭跳到前後的關鍵影格。

選取片段後，時間軸上的片段會顯示小菱形標出關鍵影格位置，點菱形可讓播放頭跳過去。

9入場、循環、出場動畫

不想手動設關鍵影格時，用現成的動畫效果最快。

  1. 選取片段，切到右側「動畫」分頁。
  2. 「入場」區點一個效果，例如淡入、左側滑入、放大出現、彈出、掉落彈跳、模糊淡入、圓形展開。點選後會自動預覽一次。
  3. 下方「長度」滑桿調整入場動畫持續幾秒。
  4. 「循環（整段持續）」區可選漂浮、呼吸、搖擺、持續旋轉、閃爍、燭光、抖動、心跳、果凍，用「速度」與「幅度」滑桿微調。
  5. 「出場」區同入場，選淡出、滑出、縮小消失等效果。
  6. 要取消效果，點該區的「無」。
標示為文字專用的效果（入場：打字機、逐字蓋章、逐字升起、逐字彈跳；循環：逐字波浪、逐字閃亮；出場：倒退刪字、逐字掉落）只對文字片段有效，會一個字一個字變化。入場與出場的時間範圍會在時間軸片段上顯示為淡色區塊。音訊與轉場片段沒有動畫分頁。

10鏡頭運鏡

鏡頭讓整個畫面推近、拉遠、平移或震動，就像移動攝影機。

  1. 點時間軸最上方的「鏡頭」列，右側面板切換成鏡頭設定。
  2. 「鏡頭位置」有中心 X、Y、縮放、旋轉、震動，操作方式和片段的關鍵影格相同（按 ◇ 記錄）。
  3. 「一鍵運鏡」會從播放頭開始建立 2 秒的動畫：推近（放大 1.35 倍）、拉遠、左移、右移、震動。
  4. 「重設」清除所有鏡頭動畫，回到置中。
  5. 鏡頭列上的小菱形是鏡頭關鍵影格，點一下讓播放頭跳過去。
鏡頭關鍵影格用的是整部影片的時間。視覺軌標頭的相機圖示控制該軌是否「跟隨鏡頭」，關掉後這一軌固定在畫面上，適合字幕、浮水印、Logo。

11時間軸（下方）

結構

  • 最上面是時間尺，再來是鏡頭列，下面是各條軌道。
  • 軌道分兩種：視覺軌（畫面內容）與音訊軌（聲音）。越上面的視覺軌畫在越上層，會蓋住下面的軌道。
  • 影片長度之後的區域以暗色顯示，超出部分不會被匯出。

移動播放頭

  1. 在時間尺上點一下或按住拖曳，播放頭跟著移動。
  2. 點軌道空白處也能移動播放頭，並取消選取。

編輯片段

  1. 點片段選取，拖曳左右移動時間。上下拖曳可移到同類型的其他軌道（視覺片段只能到視覺軌，音訊片段只能到音訊軌），目標軌道會亮起。
  2. 拖曳片段左端或右端的邊緣裁切長度。
  3. 分割：把播放頭放在片段中間，按 S 或工具列剪刀圖示，片段一分為二。
  4. 雙擊片段：右側面板跳到主要欄位（文字片段會跳到文字內容）。
  5. 在片段上按右鍵：在播放頭分割、複製、貼上、建立副本、刪除。
  6. 在軌道空白處按右鍵：貼上到這裡，會貼在點擊的時間。

12開啟、儲存與草稿

  1. 專案存成一個 JSON 檔，匯入的圖片與音訊都內嵌在檔案裡，搬到別台電腦也能直接開。
  2. 用 Chrome 或 Edge 時，第一次儲存選好位置後，之後按 Ctrl+S 會直接覆寫同一個檔案。其他瀏覽器會以下載方式存檔。
  3. 編輯中會自動把目前專案暫存在瀏覽器裡。若瀏覽器意外關閉，下次開啟編輯器會詢問「找到未儲存的草稿」，按「還原草稿」即可找回。
  4. 關閉分頁時若有未儲存的變更，瀏覽器會跳出確認。
  5. 範例專案在 examples/ 資料夾：demo.json 是 24 秒示範片，smoke.json 包含所有圖層類型。
自動暫存只是救急用，存在目前這個瀏覽器裡。重要的專案請一定要按「儲存」存成檔案。

13匯出影片與 HTML

匯出影片

  1. 按右上「匯出影片」。
  2. 對話框會顯示格式（MP4 或 WebM，依瀏覽器支援）、尺寸與影格率。
  3. 選擇範圍：整部影片，或到最後一個片段結束（片段比影片長度短時才會出現）。
  4. 按「開始錄製」，進度條顯示百分比。要中止可按「取消錄製」。
  5. 完成後自動下載影片檔。
錄製是即時進行的，1 分鐘的影片需要約 1 分鐘。錄製期間請讓分頁保持在前景，不要切換分頁或最小化視窗，否則畫面可能停格或掉格。建議使用 Chrome 或 Edge。

匯出 HTML

  1. 按右上「匯出 HTML」。
  2. 會下載一個 .html 檔，內含播放器與所有素材，雙擊就能在瀏覽器播放，可以直接放上網站分享。
匯出 HTML 需要用網址或 start.bat 開啟編輯器。直接雙擊 index.html 開啟時，瀏覽器會擋住讀取播放器檔案而匯出失敗。

15常見問題與限制

加入的素材看不到？

  • 確認播放頭在片段的時間範圍內。
  • 確認它的軌道沒有被更上面的全畫面片段（背景、粒子）蓋住，可以右鍵軌道標頭「上移」。
  • 確認軌道沒有被隱藏（眼睛圖示）。

拖不動片段或物件？

  • 檢查軌道是否被鎖定（鎖頭圖示）。
  • 播放中無法在舞台上拖曳，先按 Space 暫停。

特效沒有作用？

特效只影響它下方的軌道。把特效片段放到比內容更上面的軌道。

沒有聲音？

  • 檢查音訊軌是否靜音，以及專案設定的「主音量」。
  • 瀏覽器要求先和頁面互動（點一下）後才能播放聲音。

已知限制

  • 匯出影片需即時錄製，時間與影片長度相同，且需保持分頁在前景。
  • 影片格式依瀏覽器支援決定，部分瀏覽器只能輸出 WebM。
  • 匯入的圖片與音訊內嵌在專案檔裡，素材多時檔案會變大。
  • 舊專案片段只能整段編輯，無法修改內部元素。
  • 自動草稿只存在目前的瀏覽器，清除瀏覽器資料後就會消失。
